# 个人图书管理系统 / Book Manager

一个基于 Python 面向对象设计的命令行图书管理工具，支持图书的增删改查与 JSON 数据持久化。

## 功能

| 功能 | 说明 |
|---|---|
| 添加图书 | 按「书名 + 作者」双重查重，避免重复录入 |
| 删除图书 | 按书名 + 作者精确匹配后删除 |
| 修改价格 | 校验价格非负，输入非法时取消修改 |
| 搜索图书 | 支持书名**部分匹配**（模糊搜索） |
| 列出全部 | 打印书架上的所有图书 |
| 数据持久化 | 启动时自动从 `books.json` 加载，退出时自动保存 |

## 技术要点

- **两层类设计**：`Book` 负责单本书的数据与行为，`Library` 负责集合管理与持久化
- **`with` 上下文管理器**读写文件，自动关闭，无需手动 `close()`
- **完善的异常处理**：
  - 输入非数字 → 捕获 `ValueError` 并提示重新输入
  - JSON 文件损坏 → 捕获 `JSONDecodeError`，书架保持原样不丢数据
  - 文件读写失败 → 捕获 `OSError`
- **输入校验**：年份必须大于 0、价格不能为负，不满足则要求重新输入

## 运行

```bash
python book_manager.py
```

按菜单提示输入数字即可（1~7）。选择 7 退出时会自动保存数据。

## 依赖

仅使用 Python 标准库（`os` / `json`），无需安装任何第三方包。
